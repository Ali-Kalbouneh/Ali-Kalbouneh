### ASL Translator

A real-time computer-vision application that recognizes ASL letter gestures from webcam input using MediaPipe hand landmarks and a Random Forest classification pipeline.

**Highlights:** real-time computer vision, feature extraction and normalization, custom training-data collection, model training, prediction smoothing and webcam inference.

[View repository](https://github.com/Ali-Kalbouneh/asl-translator)
